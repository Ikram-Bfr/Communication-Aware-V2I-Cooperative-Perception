# Communication-Aware V2I Cooperative Perception

This repository contains the implementation of the framework proposed in:

**Communication-Aware V2I Cooperative Perception for Bird's-Eye-View Semantic Segmentation with Adaptive Fusion Selection**

The implementation includes:

- Camera-LiDAR local feature fusion
- RSU-to-ego BEV feature alignment
- Temporal RSU feature recovery
- D3QN-based adaptive fusion selection
- BEV semantic segmentation under V2I packet interruptions

The main implementation is provided in:

`Communication_Aware_V2I_Cooperative_Perception.ipynb`
